# پلتفرم آموزش آنلاین برنامه‌نویسی (کدلرن - CodeLearn)

یک پلتفرم جامع، مدرن و تعاملی برای آموزش آنلاین برنامه‌نویسی، انتخاب مدرس، رزرو کلاس‌های اختصاصی و برگزاری جلسات زنده ویدئویی با اساتید برتر به زبان فارسی.

---

## 🌟 ویژگی‌های کلیدی سیستم

* **معماری ماژولار Pure Frontend:** پیاده‌سازی شده با **Vanilla JavaScript (ES6+)**، **HTML5** و **CSS3 خالص** بدون وابستگی به هیچ‌گونه فریم‌ورک سنگین (No React, No Vue, No Tailwind).
* **معماری لایه‌ای (Clean Architecture):** تفکیک کامل لایه‌ها: `Page` ➔ `Service` ➔ `API Client` ➔ `Mock Data / Backend REST API`.
* **انتخاب هوشمند مدرس:** فیلتر اساتید بر اساس مهارت (پایتون، جنگو، هوش مصنوعی، ری‌اکت و...)، سطح مهارت، نرخ تدریس و امتیاز.
* **تقویم تعاملی هفتگی (RTL Persian Calendar):** نمایش وضعیت‌های زمانی با رنگ‌بندی استاندارد (🟢 زمان آزاد، 🔴 رزرو شده، ⚪ بلاک شده، 🔵 کلاس‌های دانشجو).
* **جریان رزرو چندمرحله‌ای (Booking Wizard):** فرآیند گام‌به‌گام از انتخاب موضوع و سطح تا تعیین زمان در تقویم، پرداخت شبیه‌سازی‌شده و تولید خودکار لینک جلسه.
* **پشتیبانی از چندین بستر جلسه آنلاین (Provider-based Meeting Architecture):** ماژول یکپارچه برای اتصال به **Google Meet** و **Skyroom (اسکای‌روم)** با قابلیت توسعه به Zoom و Jitsi.
* **داشبورد دانشجو:** مشاهده کلاس‌های پیش‌رو، تاریخچه جلسات، ورود به اتاق کلاس آنلاین، تراکنش‌های مالی و مدیریت پروفایل.
* **داشبورد مدرس:** مدیریت زمان‌های آزاد تقویم، افزودن تایم اسلات، تعطیلی روزها، تعیین نرخ تدریس، مشاهده لیست دانشجویان و وضعیت درآمد.
* **اتاق کلاس مجازی (Live Classroom Simulation):** شبیه‌سازی اتاق جلسه، اشتراک کد زنده، کنترل‌های صوتی و تصویری و چت کلاسی.
* **مدیریت نشست و احراز هویت (Auth & Session):** پشتیبانی از نقش‌های دانشجو (Student) و مدرس (Teacher) به همراه سوئیچر آزمایشی سریع در هدر.

---

## 🚀 راهنمای راه‌اندازی سریع

### پیش‌نیازها
* مرورگر مدرن با پشتیبانی از ES Modules (Chrome, Firefox, Safari, Edge)
* Node.js جهت سرو لوکال (یا هر وب‌سرور استاتیک نظیر Nginx / Live Server)

### اجرای پروژه
```bash
# نصب وابستگی‌های محیط توسعه
npm install

# اجرای محیط توسعه لوکال روی پورت 3000
npm run dev
```
سپس مرورگر را باز کرده و به آدرس `http://localhost:3000` مراجعه نمایید.

## 👥 اکانت‌های آزمایشی جهت بررسی

| نقش | نام کاربری / ایمیل | رمز عبور | توضیحات |
|---|---|---|---|
| **دانشجو (Student)** | `ali@example.com` | `123456` | دسترسی به رزرو، کلاس‌های آینده، پرداخت |
| **مدرس (Teacher)** | `nima@example.com` | `123456` | مدیریت تقویم تدریس، تغییر نرخ، جلسات |

> **نکته:** در هدر سایت، یک منوی کشویی تحت عنوان **«نقش جاری»** تعبیه شده است که بدون نیاز به خروج و ورود مجدد، امکان جابجایی آنی بین نقش دانشجو و مدرس را فراهم می‌سازد.
